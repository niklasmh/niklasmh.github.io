# niklasmh.github.io

Personal site for Niklas Molnes Hole — [niklasmh.no](https://niklasmh.no).

The current site is a single static `index.html` at the repo root, served via GitHub Pages. Older snapshots live in their own folders:

- `2025/` — previous design iteration
- `2023/` — original React/Vite version

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
